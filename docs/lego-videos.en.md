# Lego System — modular video script (English)

English version of `docs/lego-videos.md`. Same IDs, so pieces can be mixed and tracked across languages.
Adapted for natural spoken English, not translated word for word.

Loose pieces that combine: **Hook (H) + Body (B) + Call to action (C)**.
10 × 50 × 7 = 3,500 possible combinations. Vertical 9:16, 1080×1920.

Target length per piece:

| Piece | Length | Approx. words |
|---|---|---|
| Hook | 2–4 s | 6–14 |
| Body | 8–14 s | 25–35 |
| CTA | 3–5 s | 8–15 |
| **Final video** | **15–25 s** | |

For 30–45 s videos: Hook + 2 bodies from the same block + CTA.

---

## Recording rules

- **Every piece is a standalone clip.** No body starts with "and", "but", "so",
  or refers back to the hook. That way any piece fits with any other.
- **1 second of silence** before and after each line, looking at the camera, holding still.
  That's the margin for a clean cut.
- **At least 2 takes per piece.** If you slip, restart the whole line, not from the mistake.
- Same outfit, light and framing within a session so cuts don't show.
  For variety, shoot full sessions in another look; don't mix within one.
- On-screen text is added in editing; don't read it out.
- Name files like this so Claude can find and assemble them without asking.
  Add `_en` to keep them apart from the Spanish takes:

```
clips/
  hooks/   H01_en_t1.mp4  H01_en_t2.mp4 ...
  bodies/  B01_en_t1.mp4  ...
  ctas/    C01_en_t1.mp4  ...
  broll/   app_selfie_en.mp4  app_desires_en.mp4  app_scenes_en.mp4  final_video_en.mp4 ...
```

- **App B-roll** (shoot once with the app set to English): uploading a selfie, writing 3 desires,
  reviewing the script, viewing scenes, regenerating a scene, playing the final video,
  library, EN/ES language toggle.
- **Faceless** works too: voiceover + B-roll + generated scenes. Same script.

## Content rules (non-negotiable)

- Never promise results: no "you'll make money", "you'll lose weight", "you'll find love".
  We talk about **seeing yourself, focusing and practicing**, not getting.
- Fixed on-screen text in every video, small, at the bottom:
  *"AI-generated visualization. Results not guaranteed."*
- The people shown on the website are AI-generated: never present them as real customers.
- First-person stories (B17, B21, B28, B30, B31…) only if they're true for whoever says them.
- Don't name authors or studies.
