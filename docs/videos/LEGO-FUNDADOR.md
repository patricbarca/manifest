# Sistema «lego» de vídeos del fundador

Grabas una vez todas estas piezas; luego se combinan en muchos vídeos distintos.
Cada pieza tiene un código (H1, P2, D3…). Al montar, se eligen piezas por receta.

## Reglas para que las piezas encajen

- **Cada pieza se entiende sola.** No empieces con «And…», «So…», «Then…».
- **1 segundo de silencio** mirando a cámara antes y después de cada pieza (para cortar limpio).
- **Graba cada pieza 2 veces**: una cerca (cara) y otra a medio cuerpo. Así dos piezas seguidas no parecen un salto.
- **Misma ropa y sitio** en todo (o dos «looks» completos: A = casa, B = escritorio).
- **Di el código antes de cada toma** en voz baja («H1, toma 2»): me ayuda a encontrarlas al montar.
- Lo que va entre [corchetes] es tu historia real. No inventes nada.
- Nada de prometer resultados (dinero, salud, «it works»).

## Recetas (vídeos que salen de las piezas)

| Vídeo | Receta | Duración |
|---|---|---|
| Historia del fundador | H1 → P1 → I1 → I2 → B1 → B2 → D1 → D3 → M1 → T1 → C1 | ~50 s |
| Cómo funciona | H2 → D1 → D2 → D3 → D4 → M3 → C1 | ~25 s |
| Contra los vision boards | H5 → P3 → I2 → D3 → M1 → C4 | ~20 s |
| Reacción | H4 → M3 → M1 → T2 → C1 | ~15 s |
| Ciencia | H8 → I1 → I3 → D3 → T3 → C1 | ~25 s |
| Pregunta a la audiencia | H7 → D1 → D3 → M3 → C3 | ~18 s |
| Objetivos olvidados | H3 → P2 → I2 → D1 → D2 → D3 → M2 → C2 | ~30 s |
| Pareja *(si H6 es real)* | H6 → M3 → D3 → T1 → C2 | ~18 s |

Con 8 ganchos × las mismas recetas salen variantes para probar qué gancho funciona mejor (mismo cuerpo, gancho distinto).
